# Doubt-Driven Development (Local Copy)
Source: C:\Users\123\.gemini\config\plugins\agent-skills\skills\doubt-driven-development\SKILL.md

Core Methodology:
- A confident answer is not a correct one. Bias towards disproving, not approving.
- Look for: unstated assumptions, edge cases not handled, hidden coupling, contract violations, failure modes under unexpected input.
- Empirical verification: write concrete counter-examples and execute them to verify if a failure mode exists.
